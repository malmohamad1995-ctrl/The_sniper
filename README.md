# موقع The Sniper

موقع ثابت (HTML/CSS/JS) لا يحتاج أي خادم أو قاعدة بيانات.

## الملفات
- `index.html` — الصفحة كاملة (التصميم والمحتوى).
- `assets/data.js` — بيانات قسم الأداء والتحليلات. **هذا الملف الوحيد الذي تعدّله لتحديث النتائج ونشر التحليلات.**

## تحديث الأداء
الأرقام الحالية حقيقية من سجل صفقات الروبوت `GoldSniperV97_Journal.csv` (حساب تجريبي، 85 صفقة من 12 إلى 14 أكتوبر 2026).
1. افتح `assets/data.js`.
2. أضف سطراً لكل يوم في `days`: `{ d: "2026-10-15", trades: 20, wins: 12, r: 1.5, pnl: 9.4 }`.
3. أضف تحليلاً جديداً في أول قائمة `posts`.
4. الأسهل: اطلب من Claude تحديث الملف من سجل الصفقات مباشرة، فيعيد حساب الأيام ومنحنى R وطرق الإغلاق.

## قبل النشر
- استبدل بيانات التواصل الوهمية في قسم "لنبنِ روبوتك القادم" داخل `index.html` (تيليجرام، واتساب، البريد، رابط MQL5).

## الاستضافة
يمكن رفع المجلد كما هو على GitHub Pages أو Netlify أو Cloudflare Pages أو أي استضافة عادية.

## اللغتان (عربي / إنجليزي)
- الموقع يختار اللغة تلقائياً حسب لغة متصفح الزائر، وزر EN / ع في الأعلى يبدّلها ويتذكّر الاختيار.
- النص العربي موجود داخل index.html، والنص الإنجليزي في assets/i18n.js.
- عند إضافة منشور في assets/posts.js أضف أيضاً الحقول الإنجليزية: tag_en و title_en و body_en.
